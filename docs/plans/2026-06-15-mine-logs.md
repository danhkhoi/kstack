> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Build a `/kstack-mine-logs` skill that scans Claude Code transcripts for the current project, extracts reusable lessons via heuristic pre-filter + Sonnet 4.6, presents them in a checkbox MD file, and promotes ticked lessons to auto-memory or a repo MD file.

**Tech Stack:** Bun, TypeScript, `@anthropic-ai/sdk` (already a dep — used by `test/helpers/llm-judge.ts`), gray-matter (or hand-rolled frontmatter for memory files).

import * as fs from 'fs/promises';

export type TranscriptEntry = {
  type: string;
  timestamp?: string;
  role?: string;
  content?: unknown;
  isError?: boolean;
  toolName?: string;
  sessionId?: string;
  raw: any;
};

export async function parseTranscript(filePath: string): Promise<TranscriptEntry[]> {
  const text = await fs.readFile(filePath, 'utf8');
  const out: TranscriptEntry[] = [];
  for (const line of text.split('\n')) {
    const trimmed = line.trim();
    if (!trimmed) continue;
    let parsed: any;
    try {
      parsed = JSON.parse(trimmed);
    } catch {
      continue; // malformed line — design says skip + continue
    }
    out.push(normalize(parsed));
  }
  return out;
}

function normalize(raw: any): TranscriptEntry {
  return {
    type: raw.type ?? raw.role ?? 'unknown',
    timestamp: raw.timestamp,
    role: raw.role,
    content: raw.content,
    isError: raw.is_error === true || raw.isError === true,
    toolName: raw.name,
    sessionId: raw.sessionId ?? raw.session_id,
    raw,
  };
}
```

Note: after sampling a real JSONL line, refine `normalize()` to match the actual schema. The shape above is a starting point.

import type { TranscriptEntry } from './transcript';

export type CandidateWindow = {
  kind: 'bug-fix' | 'correction' | 'env-domain' | 'false-completion' | 'repeated';
  startIdx: number;
  endIdx: number;
  entries: TranscriptEntry[];
};

export function findBugFixWindows(entries: TranscriptEntry[]): CandidateWindow[] {
  const windows: CandidateWindow[] = [];
  for (let i = 0; i < entries.length; i++) {
    if (entries[i].type === 'tool_result' && entries[i].isError) {
      // count subsequent tool_use entries until next user message
      let toolCallsAfter = 0;
      let j = i + 1;
      while (j < entries.length && entries[j].role !== 'user') {
        if (entries[j].type === 'tool_use') toolCallsAfter++;
        j++;
      }
      if (toolCallsAfter >= 3) {
        windows.push({ kind: 'bug-fix', startIdx: i, endIdx: j, entries: entries.slice(i, j + 1) });
      }
    }
  }
  return windows;
}
```

const CORRECTION_RE = /^\s*(no|don't|stop|instead|actually|use\s+\S+\s+not|that's wrong)/i;

export function findCorrectionWindows(entries: TranscriptEntry[]): CandidateWindow[] {
  const out: CandidateWindow[] = [];
  for (let i = 0; i < entries.length; i++) {
    const e = entries[i];
    if (e.role === 'user' && typeof extractText(e) === 'string' && CORRECTION_RE.test(extractText(e))) {
      const start = Math.max(0, i - 2);
      const end = Math.min(entries.length - 1, i + 2);
      out.push({ kind: 'correction', startIdx: start, endIdx: end, entries: entries.slice(start, end + 1) });
    }
  }
  return out;
}

function extractText(e: TranscriptEntry): string {
  if (typeof e.content === 'string') return e.content;
  if (Array.isArray(e.content)) {
    return e.content
      .filter((c: any) => c.type === 'text')
      .map((c: any) => c.text)
      .join(' ');
  }
  return '';
}
```

const REBUTTAL_RE = /\b(actually|didn't|wrong|still broken|you didn't|no it|not really)\b/i;

export function findFalseCompletionWindows(entries: TranscriptEntry[]): CandidateWindow[] {
  const out: CandidateWindow[] = [];
  for (let i = 0; i < entries.length - 1; i++) {

export type RepeatedPattern = {
  kind: 'repeated';
  phrase: string;
  sessions: { sessionId: string; idx: number }[];
};

export function findRepeatedPatterns(
  sessions: { sessionId: string; entries: TranscriptEntry[] }[]
): RepeatedPattern[] {
  const seen = new Map<string, { sessionId: string; idx: number }[]>();
  for (const { sessionId, entries } of sessions) {
    for (let i = 0; i < entries.length; i++) {
      const e = entries[i];
      if (e.role !== 'user') continue;
      const text = extractText(e);
      if (!text || !CORRECTION_RE.test(text)) continue;
      const norm = normalizePhrase(text);
      if (!norm) continue;
      const list = seen.get(norm) ?? [];
      list.push({ sessionId, idx: i });
      seen.set(norm, list);
    }
  }
  const out: RepeatedPattern[] = [];
  for (const [phrase, occurrences] of seen) {
    const distinctSessions = new Set(occurrences.map(o => o.sessionId));
    if (distinctSessions.size >= 2) {
      out.push({ kind: 'repeated', phrase, sessions: occurrences });
    }
  }
  return out;
}

function normalizePhrase(text: string): string {
  return text.toLowerCase().replace(/[^a-z0-9 ]/g, ' ').replace(/\s+/g, ' ').trim().slice(0, 120);
}
```

import Anthropic from '@anthropic-ai/sdk';
import type { CandidateWindow } from './heuristics';

export type Lesson = {
  title: string;
  type: string;
  context: string;
  lesson: string;
  confidence: number;
  sourceSessionIds: string[];
};

const SYSTEM = `You analyze excerpts from Claude Code transcripts and decide whether they
contain a reusable lesson worth saving to a knowledge base. A reusable lesson is one a
future engineer (or future Claude) would benefit from knowing BEFORE making the same
mistake again.

Output STRICT JSON only. Schema:
  { "isLesson": false }
  OR
  { "isLesson": true, "title": string (under 80 chars), "type":
    "bug-fix-recipe" | "tool-correction" | "approach-redirect" | "env-gotcha" |
    "domain-rule" | "anti-pattern" | "verification-failure",
    "context": string (what happened, 1-3 sentences),
    "lesson": string (the takeaway as a directive, 1-3 sentences),
    "confidence": number 0-1 }

Be strict. If the excerpt is a one-off, unclear, or trivially obvious, return isLesson:false.`;

export async function extractLesson(
  client: Anthropic,
  window: CandidateWindow
): Promise<Lesson | null> {
  const transcript = renderWindow(window);
  const response = await client.messages.create({
    model: 'claude-sonnet-4-6',
    max_tokens: 1024,
    system: SYSTEM,
    messages: [{ role: 'user', content: `Window kind: ${window.kind}\n\nTranscript:\n${transcript}` }],
  });
  const text = response.content
    .filter((c: any) => c.type === 'text')
    .map((c: any) => c.text)
    .join('\n')
    .trim();

  let parsed: any;
  try {
    parsed = JSON.parse(extractJson(text));
  } catch {
    return null; // design: drop the candidate on invalid JSON (after one retry — see below)
  }
  if (!parsed.isLesson) return null;
  if (typeof parsed.confidence !== 'number' || parsed.confidence < 0.5) return null;
  return {
    title: parsed.title,
    type: parsed.type,
    context: parsed.context,
    lesson: parsed.lesson,
    confidence: parsed.confidence,
    sourceSessionIds: [],
  };
}

function extractJson(text: string): string {
  const fence = text.match(/```(?:json)?\s*([\s\S]+?)```/);
  if (fence) return fence[1].trim();
  return text;
}

function renderWindow(w: CandidateWindow): string {
  return w.entries
    .map((e, i) => `[${i}] ${e.role ?? e.type}: ${JSON.stringify(e.content).slice(0, 500)}`)
    .join('\n');
}
```

import * as fs from 'fs/promises';
import type { Lesson } from './llm';

export type ParsedCandidate = Lesson & { ticked: boolean; idx: number };

export async function writeCandidates(
  filePath: string,
  lessons: Lesson[],
  meta: { totalSessions: number; date?: string }
): Promise<void> {
  const date = meta.date ?? new Date().toISOString().slice(0, 10);
  const lines: string[] = [];
  lines.push(`# Lesson candidates — extracted ${date}`);
  lines.push('');
  lines.push(`${lessons.length} candidates from ${meta.totalSessions} sessions. Tick \`[x]\` to keep, then run \`/kstack-mine-logs promote\`.`);
  lines.push('');
  lines.push('---');
  lines.push('');
  lessons.forEach((l, i) => {
    lines.push(`## ${i + 1}. ${l.title}`);
    lines.push(`- [ ] keep`);
    lines.push(`**Type:** ${l.type}  **Confidence:** ${l.confidence}`);
    lines.push(`**Sources:** ${l.sourceSessionIds.join(', ')}`);
    lines.push(`**What happened:** ${l.context}`);
    lines.push(`**Lesson:** ${l.lesson}`);
    lines.push('');
  });
  await fs.writeFile(filePath, lines.join('\n'), 'utf8');
}

export function parseCandidates(content: string): ParsedCandidate[] {
  const blocks = content.split(/^## \d+\.\s/m).slice(1);
  return blocks.map((block, idx) => {
    const titleMatch = block.match(/^(.+)$/m);
    const tickedMatch = block.match(/- \[(x| )\] keep/i);
    const typeMatch = block.match(/\*\*Type:\*\*\s*(\S+)/);
    const confMatch = block.match(/\*\*Confidence:\*\*\s*([0-9.]+)/);
    const sourcesMatch = block.match(/\*\*Sources:\*\*\s*(.*)/);
    const ctxMatch = block.match(/\*\*What happened:\*\*\s*(.*)/);
    const lessonMatch = block.match(/\*\*Lesson:\*\*\s*(.*)/);
    return {
      idx,
      ticked: tickedMatch?.[1].toLowerCase() === 'x',
      title: titleMatch?.[1].trim() ?? '',
      type: typeMatch?.[1] ?? '',
      confidence: parseFloat(confMatch?.[1] ?? '0'),
      sourceSessionIds: (sourcesMatch?.[1] ?? '').split(',').map(s => s.trim()).filter(Boolean),
      context: ctxMatch?.[1] ?? '',
      lesson: lessonMatch?.[1] ?? '',
    };
  });
}

import * as fs from 'fs/promises';
import * as path from 'path';
import Anthropic from '@anthropic-ai/sdk';
import { projectLogDir } from './project-path';
import { parseTranscript } from './transcript';
import {
  findBugFixWindows,
  findCorrectionWindows,
  findFalseCompletionWindows,
  findRepeatedPatterns,
} from './heuristics';
import { extractLesson, type Lesson } from './llm';
import { writeCandidates } from './candidates';
import { titleToSlug, dedupAgainstMemory } from './dedup';

export async function runExtract(cwd: string = process.cwd()): Promise<void> {
  const dir = projectLogDir(cwd);
  let files: string[];
  try {
    files = (await fs.readdir(dir)).filter(f => f.endsWith('.jsonl')).map(f => path.join(dir, f));
  } catch {
    console.error(`No logs found at ${dir}. Verify cwd is correct.`);
    process.exit(1);
  }

  console.log(`Scanning ${files.length} sessions from ${dir}...`);
  const allWindows: { sessionId: string; window: any }[] = [];
  const perSession: { sessionId: string; entries: any[] }[] = [];

  for (const file of files) {
    const sessionId = path.basename(file, '.jsonl');
    const entries = await parseTranscript(file);
    perSession.push({ sessionId, entries });
    for (const w of [
      ...findBugFixWindows(entries),
      ...findCorrectionWindows(entries),
      ...findFalseCompletionWindows(entries),
    ]) {
      allWindows.push({ sessionId, window: w });
    }
  }

  const repeats = findRepeatedPatterns(perSession);
  console.log(`Heuristic stage: ${allWindows.length} windows + ${repeats.length} cross-session patterns`);

  const client = new Anthropic({ apiKey: process.env.ANTHROPIC_API_KEY });
  const lessons: Lesson[] = [];
  for (const { sessionId, window } of allWindows) {
    const lesson = await extractLesson(client, window);
    if (lesson) {
      lesson.sourceSessionIds = [sessionId];
      lessons.push(lesson);
    }
  }

  // Dedup against existing memory dir
  const memoryDir = path.join(require('os').homedir(), '.claude', 'projects', path.basename(dir), 'memory');
  let existingSlugs = new Set<string>();
  try {
    const files = await fs.readdir(memoryDir);
    existingSlugs = new Set(files.filter(f => f.endsWith('.md')).map(f => f.replace(/\.md$/, '')));
  } catch { /* memory dir may not exist yet */ }
  const deduped = dedupAgainstMemory(lessons, existingSlugs);

  const out = path.join(cwd, 'LESSON_CANDIDATES.md');
  await writeCandidates(out, deduped, { totalSessions: files.length });
  console.log(`✓ Wrote ${deduped.length} candidates to ${out}`);
  if (lessons.length !== deduped.length) {
    console.log(`  (skipped ${lessons.length - deduped.length} already in memory)`);
  }
}
```

```typescript
import * as fs from 'fs/promises';
import * as path from 'path';
import type { Lesson } from './llm';
import { titleToSlug } from './dedup';

const TYPE_TO_MEMORY_TYPE: Record<string, string> = {
  'bug-fix-recipe': 'project',
  'tool-correction': 'feedback',
  'approach-redirect': 'feedback',
  'env-gotcha': 'project',
  'domain-rule': 'project',
  'anti-pattern': 'feedback',
  'verification-failure': 'feedback',
};

export async function writeLessonToMemory(memoryDir: string, lesson: Lesson): Promise<string> {
  await fs.mkdir(memoryDir, { recursive: true });
  const slug = titleToSlug(lesson.title);
  const filePath = path.join(memoryDir, `${slug}.md`);

  // Skip if file already exists (idempotent)
  try {
    await fs.access(filePath);
    return ''; // already exists
  } catch { /* not present, write it */ }

  const memoryType = TYPE_TO_MEMORY_TYPE[lesson.type] ?? 'feedback';
  const body = [
    '---',
    `name: ${slug}`,
    `description: ${oneLine(lesson.lesson)}`,
    'metadata:',
    `  type: ${memoryType}`,
    '---',
    '',
    lesson.lesson,
    '',
    `**Why:** ${lesson.context}`,
    '',
    `**Sources:** ${lesson.sourceSessionIds.join(', ')}`,
    '',
  ].join('\n');

  await fs.writeFile(filePath, body, 'utf8');

  // Append to MEMORY.md
  const indexPath = path.join(memoryDir, 'MEMORY.md');
  const indexLine = `- [${lesson.title}](${slug}.md) — ${oneLine(lesson.lesson).slice(0, 100)}\n`;
  await fs.appendFile(indexPath, indexLine, 'utf8');

  return filePath;
}

function oneLine(s: string): string {
  return s.replace(/\s+/g, ' ').trim();
}

import * as readline from 'readline/promises';
import { stdin, stdout } from 'process';
import { parseCandidates } from './candidates';
import { projectLogDir } from './project-path';
import * as os from 'os';

export async function runPromote(cwd: string = process.cwd()): Promise<void> {
  const candPath = path.join(cwd, 'LESSON_CANDIDATES.md');
  let content: string;
  try {
    content = await fs.readFile(candPath, 'utf8');
  } catch {
    console.error(`No LESSON_CANDIDATES.md found. Run extract first.`);
    process.exit(1);
  }

  const parsed = parseCandidates(content);
  const ticked = parsed.filter(c => c.ticked);
  if (ticked.length === 0) {
    console.log('No ticked lessons. Edit LESSON_CANDIDATES.md and tick `[x]` next to keepers.');
    return;
  }

  const rl = readline.createInterface({ input: stdin, output: stdout });
  console.log(`Found ${ticked.length} ticked lessons.`);
  console.log('Where should they go?');
  console.log('  1. Auto-memory (~/.claude/projects/<proj>/memory/)');
  console.log('  2. A markdown file in this repo');
  console.log('  3. Cancel');
  const answer = (await rl.question('> ')).trim();

  if (answer === '1') {
    const memoryDir = path.join(os.homedir(), '.claude', 'projects', path.basename(projectLogDir(cwd)), 'memory');
    for (const lesson of ticked) {
      const written = await writeLessonToMemory(memoryDir, lesson);
      console.log(written ? `✓ ${path.basename(written)}` : `(skipped, already exists: ${lesson.title})`);
    }
  } else if (answer === '2') {
    const target = (await rl.question('File path (default: LESSONS.md): ')).trim() || 'LESSONS.md';
    await appendLessonsToFile(path.join(cwd, target), ticked);
    console.log(`✓ Appended ${ticked.length} lessons to ${target}`);
  } else {
    console.log('Cancelled.');
  }
  rl.close();
}

async function appendLessonsToFile(filePath: string, lessons: Lesson[]): Promise<void> {
  const date = new Date().toISOString().slice(0, 10);
  const lines = [`\n## Lessons learned (mined ${date})\n`];
  for (const l of lessons) {
    lines.push(`### ${l.title}`);
    lines.push(`*Type: ${l.type} · Confidence: ${l.confidence} · Sessions: ${l.sourceSessionIds.join(', ')}*`);
    lines.push('');
    lines.push(`**Context:** ${l.context}`);
    lines.push('');
    lines.push(`**Lesson:** ${l.lesson}`);
    lines.push('');
  }
  await fs.appendFile(filePath, lines.join('\n'), 'utf8');
}

Extract reusable lessons from this project's Claude Code transcripts.

## When to use

- After a long stretch of work where you've corrected Claude repeatedly
- Before onboarding a teammate (mine your own corrections into a shared lessons file)
- Periodically (monthly) to capture institutional knowledge

## How it works

Two phases:

1. **Extract** scans `~/.claude/projects/<this-project>/*.jsonl`, runs heuristic
   pre-filter, then asks Sonnet 4.6 to identify reusable lessons. Writes
   `LESSON_CANDIDATES.md` to the repo root.

2. **Promote** reads the ticked lessons (you tick `[x] keep` next to keepers),
   asks where to save them, and writes to either auto-memory or a markdown file.

## Usage

```bash
# Phase 1: extract candidates (paid, ~$0.10/run)
bun mine-logs/src/cli.ts extract

# Edit LESSON_CANDIDATES.md, tick `[x]` next to keepers

# Phase 2: promote ticked lessons
bun mine-logs/src/cli.ts promote
# Prompts: memory / MD file / cancel
```

## Prerequisites

- `ANTHROPIC_API_KEY` env var set
- You've used Claude Code in this project at least a few times

## What gets extracted

- **Bug fix recipes** — error → root cause → fix patterns
- **Tool/command corrections** — "use bun test not npm test"
- **Approach redirects** — "do it this way instead"
- **Env gotchas** — hidden config / setup quirks
- **Anti-patterns** — patterns you told Claude to stop using
- **Verification failures** — "claimed done but wasn't"
- **Repeated mistakes** — same correction across multiple sessions

## Output destinations

- **Auto-memory** (recommended for personal lessons): writes to
  `~/.claude/projects/<proj>/memory/lesson_<slug>.md` with proper frontmatter.

- **Repo MD file** (recommended for team-shareable lessons): appends to a file

## Risk callouts

- **JSONL schema drift:** Claude Code's transcript format may change. The parser
  is defensive (skip malformed lines) and the heuristics inspect a small set of
  fields. If extraction quality drops, sample a fresh transcript and update
  `normalize()` in `transcript.ts`.

- **LLM cost overrun:** Stage B fires once per heuristic window. A noisy session
  could produce 50+ windows → ~$0.50/run. If this happens, add a `--limit N`
  flag to cap window count, deferred to v2.

- **Memory bloat:** Promoting too many lessons could bloat `MEMORY.md` past the
  200-line truncation threshold (per the auto-memory rules). Periodically prune
  memory files; consider an explicit `mine-logs prune` subcommand in v2.

- **Concurrent kstack sessions:** Because `.claude/skills/kstack` may symlink to
  the working dir (per CLAUDE.md), a broken `SKILL.md.tmpl` change would break
  other in-flight kstack sessions. Test template changes before committing.
